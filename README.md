# Banking Customer Spending Analysis

## Overview
This project analyzes banking transaction data to understand customer spending behaviour, identify popular merchant categories, and explore spending trends across age groups and time.

## Problem Statement
Raw transaction data makes it difficult to identify spending patterns and derive meaningful business insights. This project transforms transaction records into an interactive dashboard to support data-driven decision-making.

## Tech Stack
- **Python:** Pandas, NumPy
- **Visualization:** Matplotlib, Seaborn
- **Business Intelligence:** Power BI
- **Environment:** Google Colab

## Methodology
1. Cleaned and validated transaction data.
2. Performed exploratory data analysis (EDA).
3. Created age groups and date-based features.
4. Analyzed spending by category, age group, gender, merchant, and month.
5. Built an interactive Power BI dashboard with KPI cards, charts, and slicers.

## Key Outcomes
- Identified high-spending merchant categories.
- Compared transaction amounts across customer age groups.
- Analyzed monthly transaction trends.
- Enabled interactive exploration through category, gender, and age-group filters.
- Created a consolidated dashboard for clear business reporting.

## Project Deliverables
- Google Colab notebook for data cleaning and analysis.
- Power BI dashboard (`.pbix`).
- Visualizations and summary analysis.

## Conclusion
The project demonstrates how Python and Power BI can transform raw transaction data into actionable spending insights and an interactive business intelligence dashboard.
